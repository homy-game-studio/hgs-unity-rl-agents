# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Unity project (2022.3) that hosts the UPM package `com.hgs.rl-agents` (`Assets/Package`). It trains agents with **neuroevolution** (a genetic algorithm over neural-network weights), not gradient-based/Deep Q-learning, despite what the README and package description still say. The README is marked WIP and is partly outdated (its `Agent` example uses `GetState`/`GetReward`/`ExecuteAction`; the current API is `CollectObservations`/`EvaluateOutput`).

There is no CLI build, lint, or test setup and no test suite. Work happens in the Unity Editor: open a sample scene, press Play, and the `TrainingManager` in the scene runs training. Root `*.csproj`/`.sln` files are generated by Unity and should be ignored.

Releases are automated: pushes to `master` run semantic-release (Conventional Commits, e.g. `feat:`, `fix:`, `refactor:`), then the `Assets/Package` subtree is split into a `upm` branch. Keep commit messages in that format.

## Layout

- `Assets/Package/Runtime/Scripts` is the library (`HGS.RLAgents.Runtime` asmdef, namespace `HGS.RLAgents.*`). Uses Newtonsoft.Json.
- `Assets/Package/Editor` holds the editor tooling (`HGS.RLAgents.Editor` asmdef).
- `Assets/Sample/{Driver,Stacker,ParkingTruck}` are sample environments. Each has its own Scenes, Models, and Scripts. ParkingTruck is the active one on this branch (3D truck and trailer physics).
- `Assets/Resources/Genomes/<populationId>/` holds the saved best genomes, written automatically during training (see below). Many timestamped JSON files accumulate here.

## Architecture

Training is a loop across four pieces, driven by `Training/TrainingManager` (a MonoBehaviour placed in a scene):

1. **`TrainingPhase` list**: Each phase sets the environment prefab, number of parallel environments and renderers, population size, generations, max epoch duration, and GA rates. `TrainingManager.RunPhase` clears and respawns the environments, and creates a population per model id only if one doesn't exist yet. Populations and genomes therefore carry over between phases (curriculum-style).
2. **`Simulation/SimulationEngine`** (with `SimulationSpawner`) keeps a queue of free `SimulationEnvironment` instances. An environment is a prefab containing one or more `Agent`s as children, and is overridden per sample (`EvaluateFitness`, `OnStartEpoch`, `OnFinishEpoch`). `StartEpoch` activates and respawns the agents, and `FinishEpoch` runs after `maxEpochDuration` or when the environment calls it early. It stops the agents, computes fitness, and fires `onFinishEpoch`.
3. **`Evolution/EvolutionEngine`** holds one `Population` per **model id** (`Model.id`), so multi-agent environments can evolve different agent types independently. Each population is a set of `Individual`s that each own a `Genome` (a flat `float[]` of network weights). `GeneticAlgorithm`, `Rand`, and `Population.Evolve` do selection, crossover, and mutation. `EvolutionEngine.Save` writes the best genome as JSON into `Assets/Resources/Genomes/<modelId>/` after every generation.
4. **`Agent`** (abstract MonoBehaviour) owns a `NeuralNetwork` built from its `Model` (a ScriptableObject describing the layers, in `Model.cs` and `NeuralNetworks/`). Every `evaluateInterval` seconds it runs `CollectObservations()`, then a forward pass, then `EvaluateOutput(output)`. Subclasses must also implement `Stop()` and `Respawn()`. Fitness is accumulated in `agent.fitness`.

Flow per tick (`TrainingManager.Tick`, triggered by `_shouldTick` after each finished environment): if every individual is evaluated, evolve and save. Then advance the phase once its generation count is reached. Otherwise, while free environments and unevaluated individuals both exist, pull the next individual, `SetGenome` on each agent, and `StartEpoch`. Fitness goes back to the population through `OnEnvEpochFinish`.

**Inference mode**: assigning a `TextAsset genome` on an `Agent` makes it load that JSON in `Awake` and set `active = true`, so it runs without a `TrainingManager`. `SetGenome` silently rejects (with a warning) a genome whose length differs from `Model.GetParametersCount()`. Changing a model's layers therefore invalidates the saved genomes.

`Sensors/` holds reusable observation sources (`RaySensor`, `CollisionSensor`, and 2D variants). `Debuging/` and `Training/TrainingDebugger` draw the network and training stats through `OnGUI`. Note the `Debuging` spelling in the folder name.
